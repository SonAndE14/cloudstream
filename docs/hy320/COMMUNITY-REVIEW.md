# Community review before publication

Reviewed on 2026-10-28 against upstream master 5024ace2922a148d38df2a816b483b529789cf58. Sources are maintainer comments and issues in recloudstream/cloudstream; they are evidence, not permission to claim unrelated failures fixed.

- [AI policy](https://github.com/recloudstream/cloudstream/blob/master/AI-POLICY.md): disclose AI assistance, test submitted code, respect human feedback and be able to explain and fix changes. Every upstream PR will disclose assistance and its actual validation scope.
- [Maintainer review of PR2867](https://github.com/recloudstream/cloudstream/pull/2867#pullrequestreview-4419329462): distinct features should be separate small PRs. The full personal feature branch remains in the fork; the first contribution is restricted to hardware bitmap recovery. It excludes the launcher, provider changes, recommendations, layout preferences, downloads and experimental LAN sharing.
- [HY320 report2640](https://github.com/recloudstream/cloudstream/issues/2640) and [merged fix2765](https://github.com/recloudstream/cloudstream/pull/2765): model/hardware detection and software decoding already exist upstream. Preserve that path. A runtime fallback would complement it for hardware not detected in advance, not re-fix or close that resolved report. A separately tested software-image plugin on the owner's projector does not validate the new interceptor end to end.
- [Optional ratings1779](https://github.com/recloudstream/cloudstream/issues/1779): absence of a rating is not proof of a UI defect. Preserve original personal-rating semantics and visibility controls; remove the speculative rating change from the fork before publication. Do not invent metadata.
- [Hero-image issue3030](https://github.com/recloudstream/cloudstream/issues/3030#issuecomment-4914909117): maintainers explain that a higher-resolution poster cannot be supplied when an extension does not provide it. The personal branch reuses available background artwork and provides an image placeholder, without claiming missing source artwork repaired.
- [Custom feed request300](https://github.com/recloudstream/cloudstream/issues/300): aggregated home feeds have been requested before. A future multi-source contribution should discuss how it relates to this request and stay independent of the image fallback.
- [Performance PR2125 review](https://github.com/recloudstream/cloudstream/pull/2125#pullrequestreview-3407790643): performance and correctness claims require supporting reasoning. The fork bounds concurrent work and waiting time; it has no physical-device performance benchmark and makes no measured speedup claim.

The upstream image contribution must be described as experimental until a physical device has exercised the new runtime-retry path. Unit tests of error classification and a successful build are not physical-device testing. No upstream issue should be marked fixed merely because missing metadata is hidden or a placeholder is displayed.
